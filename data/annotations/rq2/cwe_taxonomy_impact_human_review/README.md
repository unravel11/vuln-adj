# CWE Taxonomy Human Review Packet

This is a blank three-stage human review packet for all 17 taxonomy-v1 impact rows.

1. A real human annotator labels from the sealed blind worklist.
2. A different real human independently reviews the same row.
3. An author resolves the row and signs it.

Codex decisions are provenance only and must not be copied into human fields. The packet itself remains `label_is_human=false`; canonical promotion is a separate guarded step.

Edit the JSONL file as the authoritative review record. The CSV is a read-only convenience view and is not imported by the validator.
