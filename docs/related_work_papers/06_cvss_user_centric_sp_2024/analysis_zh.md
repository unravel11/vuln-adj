# CVSS Scoring Inconsistencies 用户研究：全文解析

**证据等级**：全文 PDF，20 页；IEEE S&P 2024；arXiv:2308.15259。

## 1. 论文一句话定位

论文通过参与者重复评分实验，研究同一漏洞的 CVSS 指标为何在人与时间之间不一致，并分析规范歧义与经验等因素。

## 2. 论文要解决的问题

数据库 severity 差异的上游来源可能不是数据录入错误，而是 CVSS 指标本身需要人解释。论文把视角从数据库记录移到评分者，gap 是缺少受控、可重复的人因证据。

## 3. 核心贡献拆解

全文可确认其围绕 CWE Top 25 场景开展评分研究，并包含约九个月后的重复测量。旧综述记录 196 名参与者及 68% 重评变化；这些数字可用于描述论文样本，但不能解释为所有专业分析员的稳定率。核心贡献是区分评分分歧的 metric-level 来源，而非提出跨库修正算法。

## 4. 方法揉碎讲解

参与者阅读统一漏洞材料，填写 CVSS metric/vector；研究者比较人际与个体跨时间的一致性，并关联经验和主观难度。统一材料控制信息输入，重复测量观察时间稳定性。隐含假设是实验材料足以支持实际评分，参与者构成能代表目标用户，问卷行为接近真实工作流。

## 5. 实验逻辑

实验分别回答评分结果是否一致、哪些指标最难、经验是否解释差异、同一人是否稳定。人因研究支持 construct ambiguity，但不提供 NVD/GHSA 任一条记录的事实 gold，也不能直接评价自动路由。

## 6. 论文真正证明了什么

强结论是所给任务中评分者之间以及同一人跨时间存在分歧。中等结论是部分 CVSS metric 的解释歧义比经验差异更能解释现象。弱结论才是数据库 severity 差异一定由人因造成。

## 7. 局限与风险

参与者样本、实验材料、版本和任务压力与 NVD/GHSA 实际 curation 不同；重复评分也可能受记忆或学习影响。它研究 CVSS vector，不覆盖日期、references 和版本范围。

## 8. 可复述版本

10 秒版：severity 冲突有时是构念歧义，不是简单抄错。组会版：这要求本项目把“不同但各自合理”与 factual conflict 分开，并允许 reviewer uncertain。

## 9. 对本项目的可迁移点

直接支撑 T1 必须用两位真人、保留 vector/version、报告 disagreement 与 uncertain；也反对把数据库一致当真值。不可用其用户结果预测本项目 kappa。

## 10. 审稿式评价

**Strengths**：用受控真人证据解释上游分歧。**Weaknesses**：实验评分与真实数据库流程仍有距离。**Questions**：若提供厂商/利用上下文，分歧是否降低还是转移？
