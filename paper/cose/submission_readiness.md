## Scope Risks

Computers & Security currently states that submissions featuring AI or ML as significant components are out of scope. This project uses evidence-aware LLM silver labels for provisional experiments, so the final paper must avoid presenting LLM use as the contribution or core deployed method. The safer COSE framing is:

- Core task: post-alignment structured NVD-GHSA discrepancy typing.
- Core method: deterministic field normalization, type-first discrepancy typing, evidence-constrained adjudication scaffold, and abstention.
- LLM role: provisional silver-label aid for draft experiments only, to be replaced or audited by human gold before final claims.

If the final submitted version still depends on LLM silver labels for main results, the cover letter and manuscript should clearly disclose that limitation and consider whether COSE remains the best venue.
